# Project Screenshots Guide

This directory is designated for high-resolution user interface captures of the **CSD Smart Slot Booking & Token Management System**.

### Recommended Screenshots:

1. **`01-landing-page.png`** - Public landing page featuring live canteen statistics and availability banner.
2. **`02-customer-login.png`** - Customer authentication portal with mobile number and password validation.
3. **`03-customer-dashboard.png`** - Customer dashboard displaying active bookings, status indicators, and quick action cards.
4. **`04-slot-booking.png`** - Interactive slot booking interface with card type (Grocery/Liquor), date picker, and 30-minute interval capacity cards.
5. **`05-token-qr-pass.png`** - Digital Token & QR Code verification pass ready for canteen gate presentation.
6. **`06-admin-dashboard.png`** - Administrative KPI dashboard with real-time footfall metrics, booking counts, and chart analytics.
7. **`07-member-management.png`** - Member directory with approval/rejection workflows and audit metadata.
8. **`08-slot-management.png`** - Administrative slot configuration panel (timing, capacity, activation toggles).
9. **`09-reports-analytics.png`** - Periodic occupancy reports and Excel report export triggers.
10. **`10-operator-queue.png`** - Operator desk interface for token searching, check-in, check-out, and queue monitoring.

> Place your `.png` or `.webp` files matching these filenames in this directory to display them in documentation.
